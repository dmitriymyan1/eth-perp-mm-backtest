# Take-Home Assignment

## Objective
Design a market-making bot and backtest it on three calendar days of historical data:
- Description of the market-making strategy
- Backtesting simulator, including: order fills, inventory tracking, PnL calculation
- Performance metrics for the evaluation period
- Brief conclusions and analysis

## Evaluation Requirements
- **Strategy Design:** quoting logic, inventory management, funding-rate usage
- **Backtesting Engine:** order placement and cancellation logic, fill simulation, inventory accounting, realized and unrealized PnL calculation
- **Performance Analysis:** total PnL, daily PnL, inventory statistics, fill statistics, risk metrics, any additional metrics considered relevant
